# Cape Fear Outfitters Accounting

Introductory financial accounting simulation for ACG 201.

Development source, setup instructions and validation notes are on the [staging branch](https://github.com/carterg1205/cape-fear-accounting/tree/staging).

React + TypeScript, Cloudflare Workers, D1 and R2. Students interpret business records and manually prepare journal entries.

Production deployment requires explicit owner approval. No automatic deployment is enabled.
